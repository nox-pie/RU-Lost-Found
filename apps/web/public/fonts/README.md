# Fonts

Self-hosted so the first paint doesn't wait for a third-party stylesheet.

| File                           | Font                                                                            | Licence                                                  |
| ------------------------------ | ------------------------------------------------------------------------------- | -------------------------------------------------------- |
| `inter-latin.woff2`            | [Inter](https://rsms.me/inter/) (variable, 300–700)                             | [SIL Open Font License 1.1](https://openfontlicense.org) |
| `playfair-display-latin.woff2` | [Playfair Display](https://github.com/clauseggers/Playfair) (variable, 400–700) | [SIL Open Font License 1.1](https://openfontlicense.org) |

Latin subset, downloaded from Google Fonts. To change fonts, replace these files and the
`@font-face` rules at the top of `src/index.css`.
